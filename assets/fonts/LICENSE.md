# Font licences

Both faces are self-hosted so the site makes no third-party requests.

- **Archivo** (variable, width 62–125%, weight 100–900) — Omnibus-Type. SIL Open Font License 1.1.
- **JetBrains Mono** (variable) — JetBrains. SIL Open Font License 1.1.

Files are the Latin subsets served by Google Fonts. The OFL allows bundling and
redistribution with the site; it does not allow selling the font files on their own.
